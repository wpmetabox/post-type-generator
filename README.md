# WordPress Post Type Generator

Generate PHP code for custom post types with [Meta Box](https://metabox.io).

Use the tool online: [metabox.io/post-type-generator](https://metabox.io/post-type-generator/).

## Prefer a UI in WordPress?

This generator creates code that you paste into your theme. If you want to build post types inside the WordPress admin, use **[Meta Box Lite](https://metabox.io/lite/)**.

Meta Box Lite is a free plugin. It combines Meta Box, Meta Box Builder, and all free extensions. With it you can manage:

- Custom post types
- Taxonomies
- Custom fields
- Relationships

All of this uses a visual UI. You do not need to copy and paste code.

## Need premium features?

Upgrade to **[Meta Box AIO](https://metabox.io/aio/)** when you need advanced tools. Meta Box AIO includes all free and premium Meta Box extensions in one plugin.

Examples of premium features:

- Repeatable field groups
- Conditional logic for fields and field groups
- Advanced location rules
- Custom fields for users and taxonomies
- Settings pages and Customizer panels
- Frontend submission forms
- Views to display field data on the frontend
- Custom Gutenberg blocks
- Custom database tables for better performance

## Develop locally

This project uses [Vite](https://vitejs.dev/).

Install dependencies:

```sh
pnpm install
```

Start the development server:

```sh
pnpm start
```

Build for production (output goes to `build/`):

```sh
pnpm build
```
